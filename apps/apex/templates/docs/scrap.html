scrap

https://scrap.farfield.systems

A pastebin: text and code snippets with syntax highlighting, optional expiry, and three visibilities — public, unlisted, and token-locked. A locked paste is shareable by URL but opens only with its access token, which can be rolled or removed at any time without changing the URL.

Public surface

GET/pastes
The public paste index.
GET/{id}
A paste, rendered with syntax highlighting. Unlisted pastes resolve here but are not indexed; locked pastes prompt for their token.
GET/{id}/raw
The paste body as plain text — curl-friendly.
GET/status
Health check.

API

Write operations take the env key or a minted ffk_… key (scope write, app scrap) as X-API-Key or a bearer token.

POST/api/pastes
Create a paste — body, title, language, visibility, expiry.
DELETE/api/pastes/{id}
Delete a paste.
POST/api/pastes/{id}/token/roll
Roll a locked paste's access token.
DELETE/api/pastes/{id}/token
Remove the lock entirely.

Housekeeping

Expired pastes are deleted (with their tokens) by an hourly sweep and again on demand; nothing lingers past its expiry. The admin console can also purge everything expired in one action.
