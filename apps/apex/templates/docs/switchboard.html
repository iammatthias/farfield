switchboard

https://switchboard.farfield.systems

The fleet's iMessage front door. Photon delivers an inbound iMessage to a signed webhook here; switchboard authenticates it, works out what the message meant, dispatches it to the app that owns that job, and replies in the same thread. It holds the sibling API keys so the phone never has to — and deliberately holds no blobs key, because feed owns blob uploads.

Message grammar

The default is capture, so the common case needs no syntax: type a thought, send it. A message that is only a URL becomes a bookmark instead, because that is what sharing a bare link means. Photos sent together arrive as one message and become one post.

textany words
A feed post. Trailing #hashtags become tags.
texta bare link
A bookmark, with OpenGraph metadata fetched server-side.
photoswith or without a caption
A feed post with the images, stored in blobs at full fidelity.

Commands

/scraptext

/qrurl [label]
Create a QR code; replies with the image inline.

Fleet health roll-up, probed live.
/pulse
Uptime targets and any open incidents.
+text
Append to the last post, within 15 minutes.
/tagsa, b
Replace the tags on the last post.
/undo
Reverse the last action, whichever service owned it.
/help
The command list, in the thread.

Public surface

POST/hooks/photon
The Photon webhook. HMAC-gated, not key-gated.
GET/status
Health check, plus whether the hook and line are configured.

Authentication

Photon signs every delivery: HMAC-SHA256 over v0:{timestamp}:{rawBody}, sent as X-Spectrum-Signature. switchboard verifies it against the raw bytes before parsing anything, refuses timestamps outside five minutes, dedupes on the message id so a redelivery cannot act twice, and requires the sender to be in the allowlist.

Both gates fail closed. With no signing secret the route returns 404 rather than accepting unsigned deliveries; with an empty allowlist every message is ignored. That is deliberate — the endpoint is public by necessity and publishes to a public feed, so the failure mode of a half-configured service must be silence, not a stranger's words on the site.

A message from an unknown sender is logged and dropped without a reply, since answering would confirm the number is live. Rejections return 2xx, because Photon retries only on 5xx and none of these are fixed by retrying.

Housekeeping

The message log is dedupe record, audit trail, and undo target at once. It is bounded at 90 days by an hourly sweep — the records it points at live in the apps that own them, so nothing is lost when a log row ages out.
