epochs

epochs.farfield.systems

A frontend for the Epochs contract on Ethereum mainnet — a crypto-native temporal wayfinding system in which the base unit is one Ethereum block and each concentric epoch is 11n blocks long, from 111 up to 1111.

This app is a rebuild of epochs.cosmiccomputation.org, the Cosmic Computation Laboratory site that went offline. It is reconstructed from that site's own webpack bundles and its Wayback capture, and it is deliberately not in the Farfield house style: the palette, type scale, spacing, copy and the concentric-circle diagram are reproduced as they were. Only the stack is Farfield.

The system

Every block has twelve simultaneous epoch readings, each cycling 1 through 11:

epochs[i] = ((blockNumber / 11**i) % 11) + 1

The twelve are named Block, Form, Structure, Bloom, Episode, Phase, Season, Revolution, Aepoch, Aera, Arche and Aeon. A Season is 1,771,561 blocks — roughly nine months. A Revolution is 19,487,171 blocks, a little over eight years; the second one began in March 2024.

Contract

Address 0xde9f0c369Ef3692B4bF9D40803A9029a3722B9c4 on Ethereum mainnet, controlled by AspectsDAO. Inspect it on Etherscan.

The interface is read-only — getEpochs(uint256) is pure, currentEpochs() and getEpochLabels() are view. There is no wallet, no login and nothing to sign. The epoch names come from getEpochLabels() rather than being hardcoded, so if the owner renames them the page follows.

How it works

The original read the chain from the browser on every block. Here the server polls instead, once per slot, and every visitor is served the same warm reading — so the page costs no RPC calls per request and renders fully with JavaScript disabled. A small script keeps an open tab current by polling /api/current.

Each poll is a single JSON-RPC batch: eth_blockNumber and currentEpochs() together, plus getEpochLabels() only until the names have been read once. currentEpochs() is used rather than getEpochs(n) precisely because it reads block.number on-chain, so it needs no argument and can ride in the same batch instead of waiting for the height. That makes a cold start one round trip rather than three.

Because the height and the epochs are separate sub-requests, a provider can answer them one block apart. When they disagree the values are recomputed from the height about to be displayed, so the page never shows a block whose epochs belong to its neighbour.

The last good reading is cached in SQLite, so a restart during an upstream RPC outage still renders real numbers instead of a loading state. On a genuinely cold start the first request waits up to 2.5s for the first poll rather than serving a loading page. Epoch values come from the contract; the identical local computation is the fallback, and a test pins the two together against twenty readings captured from the deployed contract in 2022.

Endpoints and failover

Endpoints are tried in order and the one that answers is preferred for subsequent polls, so an unreachable first choice costs one failed attempt rather than one on every poll forever. The preference is re-evaluated every ten minutes so an endpoint that recovers is picked back up.

The endpoint actually in use is reported on /status as rpc, and a change is logged with the error that caused it. If a configured provider is being silently skipped, that is where it shows.

The built-in RPC endpoints are public and rate-limited. Point EPOCHS_RPC_URL at your own provider for anything beyond casual traffic.

What was recovered, and what was not

The rebuild was reconstructed from the site's webpack bundles and its Wayback capture. Recovered in full: the contract ABI, the stitches theme tokens, every component style, all page copy, the twenty milestone events with their transaction hashes, and the document metadata.

Two things are gone for good, confirmed against the Wayback index rather than assumed:

  • The social card. og:image and twitter:image pointed at /images/site-preview.png?42069. The archive holds no capture of anything under /images/, so the art does not exist anywhere. Those two tags are omitted rather than left pointing at a 404, which would render a broken preview everywhere the link is shared.
  • New Spirit. The heading face was never archived — only the two Söhne Mono weights were.

/favicon.ico is listed in the index at 1,924 bytes but its replay currently returns 404, so the page uses the Farfield mark. It is worth retrying.

Fonts

The original set its headings in New Spirit and its body in Söhne Mono. Both are licensed and are not redistributed here, so the page falls back to a system serif and a system mono — close in character, not identical. Drop the three original woff2 files into a directory, point EPOCHS_FONTS_DIR at it, and the page serves and declares them.

API

GET /api/current returns the live reading as JSON: block height, the twelve epoch values, their labels, and whether the reading is current or a cached fallback. It is public, like the contract behind it.
