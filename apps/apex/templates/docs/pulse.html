pulse

https://pulse.farfield.systems

The fleet's observability service: uptime monitoring from the outside and traffic analytics from the inside, in one session-gated console. The only public surface is GET /status, which exposes nothing beyond a target count.

Uptime

A checker loop probes configured HTTP targets — the fleet's public URLs, through the Cloudflare tunnel, the same path a real visitor takes — each on its own cadence. Every probe outcome is recorded; the console shows 24h/7d/30d uptime percentages, latency sparklines, and an incident log.

Failure handling is two-stage so tunnel flakes do not page as outages: a failed probe is retried once and only the retry's outcome is recorded, and an incident opens only after consecutive recorded fails (recovery closes on the first ok, undebounced). Raw probe results are kept for 45 days; incidents are kept forever.

Traffic

Every other farfield app records one row per handled request into a telemetry sidecar database via lib/pulse. Privacy is by construction: no raw IP and no raw User-Agent are ever stored — a request is attributed to a visitor key derived from a salt that lives only in memory and rotates at UTC midnight, so visitors cannot be linked across days even with the database in hand.

Pulse's collector sweeps those sidecars every few minutes and folds them into daily aggregates: hits and exact uniques per day/app/path, and referrer counts. Raw rows age out after 14 days; the aggregates are the permanent record.

Console

GET/
Overview — every target's state, uptime windows, and recent incidents.
GET/targets
Target CRUD — URL, expected status, per-target probe interval.
GET/traffic
Per-app daily hits, uniques, paths, and referrers.
GET/status
Health check — {"service":"pulse","ok":true,"targets":N}.

Relation to the fleet status page

farfield.systems/status is a live snapshot from inside the compose network — is every process answering right now. Pulse is the instrument with memory: it measures the public path, keeps history, and knows what happened last Tuesday. A broken tunnel shows only in pulse; a blip three days ago shows only in pulse.
