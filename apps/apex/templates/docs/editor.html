editor

lib/editor · lib/wat · apps/desk

The writing surface in content, feed and scrap. A rich Markdown editor written by hand in WebAssembly text — the document, the Markdown styling, a TrueType rasterizer, line layout and every pixel it shows. The page supplies input and a surface; it never draws text with the DOM. The same module runs in a browser on a <canvas> and on the desktop under wazero.

Writing

  • Markdown styles itself as you type: headings, emphasis, inline code, links, lists, quotes, code blocks and rules. The markers stay visible, dimmed, so the source is always the truth.
  • A quiet strip of commands sits above the text; a small bar floats over any selection; type / at the start of a line for a menu of blocks.
  • Paste or drop an image to upload it to blobs as blob://<cid>. A line that is only an image — ![](blob://…) or any image URL — shows the image beneath its Markdown, drawn by the editor like everything else.
  • The Markdown toggle at the end of the strip shows the raw source, unstyled and without images — exactly what saves. It is remembered per browser.
  • ⌘S saves in place. Undo groups by word. Lists continue on Enter; Tab nests.
  • Scrap uses a plain mode with no Markdown styling.

Pieces

SourceJob
mem.watThe memory map: fixed regions for text, fonts, glyph cache, layout and the framebuffer
text.watThe UTF-8 buffer, words and positions
font.watA TrueType reader and a signed-area rasterizer — checked against x/image/vector to within 0.3% of ink
markdown.watLine classes and per-byte inline styles
layout.watWrapping at a reading measure, heading weights and tracking
render.watThe software renderer into an RGBA framebuffer
edit.watThe host API: keys, commands, pointer, selection, undo, page scroll

The whole engine is about 20 KB of WebAssembly; the brand faces (Newsreader, IBM Plex Mono) are the weight and are cached for a year. No binary is committed: lib/wat assembles the text format in pure Go at start, in milliseconds.

Using it

An app serves the assets with editor.Handler("/static/editor/") and marks a field:

<textarea name="body" data-editor data-editor-upload="/embed/blob">…</textarea>
<link rel="stylesheet" href="/static/editor/host.css?v={{"{{"}}editorVer{{"}}"}}">
<script src="/static/editor/host.js?v={{"{{"}}editorVer{{"}}"}}" defer></script>
<script src="/static/editor/mount.js?v={{"{{"}}editorVer{{"}}"}}" defer></script>

The textarea stays in the form and posts as always — without JavaScript, or if the module fails to load, the page still edits plain Markdown. go run ./lib/editor/cmd/preview serves the component gallery with the live editor on a document page.
